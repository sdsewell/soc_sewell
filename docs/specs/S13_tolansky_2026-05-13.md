## 1. Purpose

Given a set of calibration fringe ring radii for **two known neon
wavelengths**, recover the etalon physical parameters that M05 (S14)
needs as starting priors:

| Parameter | Symbol | Physical meaning |
|-----------|--------|-----------------|
| Plate scale | α | Angular pixel scale (rad/px) |
| r²-spacing | Δₐ, Δᵦ | Mean successive r²-differences per line (px²) |
| Fractional orders | εₐ, εᵦ | Fractional interference order at optical axis |
| Plate spacing | d | Etalon mirror separation (m); Benoit recovery |

The analysis follows Vaughan (1989) §3.5.2, Eqs. (3.83)–(3.97), with
WLS refinement to obtain propagated 1σ uncertainties.

### 1.1 Why there is no single-line Tolansky step

An earlier spec (S13b) described a single-line Tolansky analysis applied
to airglow science images to recover α as a consistency check.  This step
is **not part of the WindCube pipeline** and S13b is retired.

The reason: α is already recovered with full uncertainty from the two-line
neon calibration (this module) and passed as a fixed prior to M05/M06.
Airglow science images go directly from annular reduction into the M06 Airy
forward-model inversion; no intermediate Tolansky analysis of the airglow
rings is needed or performed.

`tolansky_1line_2026-05-05.py` is therefore retired as dead code.

- 10-column input: col 9 (`line_id`) used directly; rows with line_id

## 3. Notation (Vaughan §3.5.2 correspondence)

Vaughan works with ring **diameters** D_p (mm); this module uses ring
**radii** r_p (pixels).  Since D_p = 2r_p, all D² terms become r²/4
(factor absorbed once here, silent throughout).

| Vaughan | This module | Units | Meaning |
|---------|-------------|-------|---------|
| ₐD²_p/4 | r²_p (line a) | px² | Radius-squared, p-th ring, line a |
| Δₐ/4 | Δₐ | px² | r²-spacing, line a |
| ₐε_c | εₐ | — | Fractional order at axis, line a |

Ring indexing: p = 1 for innermost ring (Vaughan uses p = 0; offset by 1).

## 4. Algorithm

### Step 1 — Successive r²-differences

```
Δₐ = f²_px · λₐ / (n_air · d)    [Vaughan 3.85]
Δᵦ = f²_px · λᵦ / (n_air · d)    [Vaughan 3.87]
Δₐ / Δᵦ = λₐ / λᵦ = 640.2248 / 638.2991 = 1.003017
```

Warn if observed ratio deviates from 1.003017 by > 200 ppm.

### Step 2 — Rectangular array (Vaughan Table 3.1)

Lays out r²_p values as columns; successive differences δ_p between them.
Any δ_p markedly different from mean Δ flags a bad ring.

### Step 3 — WLS fit: r²_p = S·p + b

Weights w_p = 1 / σ(r²_p)².  Closed-form normal equations
(Bevington & Robinson §6.3):

```
Λ = Σw · Σwp² − (Σwp)²
S = (Σw · Σwpr²  −  Σwp · Σwr²)  / Λ        ← Δ
b = (Σwp² · Σwr²  −  Σwp · Σwpr²) / Λ
Var(S) = Σw   / Λ
Var(b) = Σwp² / Λ
ε = 1 + b/S   (mod 1, wrapped to [0, 1))
σ(ε)² = (σ_b/S)² + (b·σ_S/S²)²
χ²_dof = Σ w·(r² − S·p − b)² / (N − 2)
```

Applied independently to each family; yields Δₐ, εₐ, Δᵦ, εᵦ.

### Step 4 — Benoit d recovery (Vaughan Eqs. 3.94–3.97)

```
N_Δ = round(2 · d_prior · (1/λₐ − 1/λᵦ))     [integer disambiguation]
d   = (N_Δ + εₐ − εᵦ) · λₐλᵦ / (2·n_air·(λᵦ − λₐ))
σ_d = λₐλᵦ / (2·n_air·|λᵦ−λₐ|) · √(σ²_εₐ + σ²_εᵦ)
```

d_prior = 20.008 mm (ICOS build report, spacer measurement).  Used
**only** to resolve the integer N_Δ = −189; does not bias recovered d.

### Step 5 — Plate scale α recovery (Vaughan Eq. 3.85 rearranged)

```
α  = √(λ · n_air / (d · Δ))
σ(α)/α = (1/2) · √( (σ_Δ/Δ)² + (σ_d/d)² )
```

Computed for each family independently; alpha_mean = (α_a + α_b) / 2.
Warn if |α_a − α_b| / α_a > 1000 ppm.

```python
    "alpha_init":    result.alpha_mean,
    "alpha_bounds":  (result.alpha_mean × 0.875,
                      result.alpha_mean × 1.125),

}
```

## 11. Retired: S13b single-line Tolansky

S13b (`S13b_tolansky_1_line_2026-05-05.md`) described a Tolansky analysis
of the airglow fringe rings to recover α as a consistency check.  It is
retired for the following reason:

α is recovered from the neon calibration image via this module (S13) and
passed as a fixed prior to M05 and M06.  The M06 Airy inversion operates
directly on the 1-D radial profile from annular reduction; it does not
require a Tolansky pre-analysis of the airglow rings.  Implementing S13b
would add a processing step with no science output.

`tolansky_1line_2026-05-05.py` and `tolansky-1line.py` are retained in the
repository as historical reference but are not called by any pipeline module.
