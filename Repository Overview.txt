1) gen01_synthetic_metadata_generator_2026_04_16.py
    Simulates the entire mission (or an 'n' day subset) with modeled calibration, dark and science (airglow) 
    images each of which is sampled at the correct time and embedded with realistic metadata
    -> soc_synthesized_data\2x2_binned\bin_frames
    -> soc_synthesized_data\GEN01_20270101_001.0d_uniform_seed0042.xlsx

2) load_image.py
    Prompts the user to Load and display a WindCube FPI binary image, asks the user to visually select the 
    coarse center position of the fringes cx_coarse, cy_coarse.  It also uses a nominal (216x216) region of interest
    to create a ROI npy array used in the next steps

3) centre_finder.py — Two-pass azimuthal variance minimisation for FPI ring centre.
    Inputs: cal_image_L1.1.npy (or equivalent) generated by running load_real_image.py
    Outputs-1: cal_image_step2_centre.png
    Output-2: cal_image_centre.npz (the new seed used by annular_reduction.py)

    Stage 1 — coarse grid search over ±var_search_px.
    Stage 2 — Nelder-Mead from the best grid point.

    Centre uncertainty is estimated from cost-surface curvature (finite-difference
    second derivative at the minimum).

4) annular_reduction.py
    Requires a pre-determined fringe centre produced by center_finder.py
    (saved as 2027-01-01T00-00-00Z_science_ROI_L1.1_center.npz).  No centre finding is performed here.

    1. Select image ROI (e.g. 2027-01-01T00-00-00Z_science_ROI_L1.1.npy) produced by load_image.py
    2. Select corresponding _centre.npz (cx, cy, sigma_cx, sigma_cy) produced by center_finder.py
    3. Annular reduction → 1-D radial intensity profile (FringeProfile).
        Peak finding and Gaussian fits are performed here, on the profile
        and SEM arrays as soon as they are available.
    4. Save _L1.2.npz with all fields required by M05.
    5. Save cal_image_L1.3.npy  (r_grid | profile | sigma_profile).
    6. Plot: image with centre | radial profile with labelled peaks.

    References:
    Harding et al. (2014) Section 3
    Niciejewski et al. (1992) SPIE 1745
    Mulligan (1986) J. Phys. E 19, 545

5) tolansky_2line.py
    Follows Vaughan and uses Benoit's method of exact fractions to extract an accurate value for etalon gap
    'd' given the two well known wavelengths present in the neon calibraton lamp (and which are passed by
    the 640 +/- 5 nm bandpass filter)
    This routine also returns a value for the plate-scale 'alpha'[radians per pixel] used in Harding Equation (3)

6) tolansky_1_line.py
    This routine operates on the radial profile for a single line (airglow) image produced by annular_reduction.py
    It is only able to return the fractional fringe order 'epsilon' at image center.  This must be used
    with the etalon gap 'd' value determined in tolansky_2_line.py in order to retrieve the doppler shifted velocity
    of the oxygen emission line.

8) H03_airglow_synthesis_2026_05_12.py
    Purpose: Generate a synthetic OI 630 nm airglow fringe image using the
    WindCube FPI forward model, display it with its pixel histogram,
    and optionally save the image and 1D profile as .npy files.

    This script is the interactive companion to m03_airglow_synthesis.
    It prompts the user for all parameters that vary on orbit, provides
    physically motivated defaults, then calls synthesise_airglow_image()
    and displays the result.

9) H06_airglow_inversion_2026_05_13.py
    Purpose: Load an OI 630 nm airglow fringe profile (real or synthetic),
    load a calibration result from H05, run the H06 staged airglow
    inversion to recover the line-of-sight wind velocity, and produce
    a diagnostic figure modelled on Harding et al. (2014) Fig. 5.
